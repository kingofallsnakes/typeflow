# Cobra — Adaptive Typing Coach

An adaptive touch typing coach that analyses every keystroke, finds your weakest keys and transitions, and builds practice around them. Build muscle memory, one keystroke at a time.

## Development

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```

## Built with

- TanStack Start
- TypeScript
- React
- Tailwind CSS
- Supabase
